# React Development Assignments

A unified repository containing React applications covering fundamental to advanced front-end concepts, built with Vite, modular component architecture, and modern dark-mode glassmorphic styling.

## 🛠️ Tech Stack

- **Core Library:** React 18+
- **Build Tool:** Vite
- **Routing:** React Router v6
- **State Handling:** React Hooks (`useState`, `useEffect`, `useContext`)
- **Styling:** Vanilla CSS with custom glassmorphism effects
- **Deployment Platform:** Vercel
